# Telecom Customer Churn Analysis

## Project Overview
This project was completed as part of the Business Analyst Internship at SaiKet Systems.

The objective of this project is to analyze the Telecom Customer Churn dataset, clean the data, perform exploratory data analysis (EDA), visualize customer behavior, and identify factors influencing customer churn.

---

## Project Objectives

- Understand the dataset
- Clean and preprocess the data
- Perform exploratory data analysis
- Segment customers based on tenure
- Analyze customer churn using different business factors

---

## Tools & Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- PyCharm

---

## Dataset

- Dataset Name: Telco Customer Churn Dataset
- Total Records (Original): 7043
- Total Records (After Cleaning): 7032
- Features: 21 Columns

---

## Tasks Completed

### Task 1 - Understand the Dataset
- Loaded dataset using Pandas
- Displayed first 10 rows
- Identified data types
- Checked missing values

### Task 2 - Data Cleaning
- Converted TotalCharges to numeric
- Handled missing values
- Removed missing records
- Checked duplicate records
- Standardized column names
- Saved cleaned dataset

### Task 3 - Exploratory Data Analysis
- Calculated Mean, Median and Mode
- Created Histograms
- Created Box Plots
- Analyzed Churn vs Non-Churn

### Task 4 - Customer Segmentation Visualization
- Created tenure categories
- Donut Chart
- Average Monthly Charges Bar Chart

### Task 5 - Advanced Analysis
- Tenure Analysis
- Churn by Gender
- Churn by Senior Citizen
- Churn by Payment Method
- Churn by Contract Type

---

## Key Insights

- Approximately 26.58% of customers churned.
- Customers with 0–12 months tenure had the highest churn rate.
- Customers with 37+ months tenure had the lowest churn rate.
- Gender had minimal impact on customer churn.
- Payment method and contract type influenced customer churn.
