# Customer Segmentation Visualization & Advanced Analysis

## 📌 Project Overview

This project was completed as part of the **Business Analyst Internship** at **SaiKet Systems**. The objective of this project is to perform customer segmentation and advanced business analysis using the **Telco Customer Churn Dataset**.

The project focuses on understanding customer behavior, cleaning and preprocessing the dataset, performing exploratory data analysis (EDA), visualizing customer segments, and generating meaningful business insights that can help organizations understand customer churn patterns and improve customer retention strategies.

The analysis was carried out using Python and popular data analysis libraries such as Pandas, Matplotlib, and Seaborn.

---

# 🎯 Project Objectives

The primary objectives of this project are:

- Understand the structure of the dataset.
- Explore the features and identify data quality issues.
- Perform data cleaning and preprocessing.
- Handle missing values and duplicate records.
- Standardize the dataset for analysis.
- Perform Exploratory Data Analysis (EDA).
- Visualize customer behavior using charts and graphs.
- Segment customers based on tenure.
- Analyze customer churn using demographic and service-related attributes.
- Generate business insights to support data-driven decision making.

---

# 📊 Dataset Information

**Dataset Name:** Telco Customer Churn Dataset

This dataset contains customer information from a telecommunications company and is commonly used for customer churn prediction and business analytics projects.

### Original Dataset

- Total Records : 7043
- Total Features : 21 Columns

### Dataset After Cleaning

- Total Records : 7032
- Total Features : 21 Columns

The dataset includes customer demographic information, subscribed services, payment methods, contract details, billing information, and customer churn status.

# 📈 Key Business Insights

The analysis produced several meaningful business insights:

- Approximately **26.58%** of customers left the company (Customer Churn).
- Approximately **73.42%** of customers remained with the company.
- Customers with **0–12 months** of tenure showed the highest churn rate.
- Customers with **37+ months** of tenure showed the lowest churn rate.
- Gender had minimal impact on customer churn.
- Contract type influenced customer retention.
- Payment methods showed different churn patterns.
- Long-term customers were more likely to stay with the company.

These insights can help organizations improve customer retention strategies and reduce churn.
